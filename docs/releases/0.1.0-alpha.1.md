[consumption and local overrides](https://github.com/kkrausse/browser-agent-toolkit/blob/integration/upstream-runtime/docs/RELEASING.md).

including public packages. CI can use a repository-authorized `GITHUB_TOKEN`.

## Scope

This is an experimental release for external integration, not full Node/Bun
compatibility qualification. The retained runtime suite still fails on missing
`worker_threads.markAsUncloneable`; further compatibility dispositions and crash,
cross-document contention, quota and interrupted-write qualification remain open.
Orderly persistence/reopen tests do not establish crash durability.

There is no new umbrella licensing grant. Existing upstream/chat licenses and
notices are preserved; Workspace metadata remains `UNLICENSED`.
