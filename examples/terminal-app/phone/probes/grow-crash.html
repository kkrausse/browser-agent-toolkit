That is the point: in Playwright's WebKit 27.2 the "race" run kills the web process within about a second (a JavaScriptCore fault when a shared WebAssembly.Memory grows while a worker holding instances of it is torn down; report section 9.1). Safari may answer with "A problem repeatedly occurred" or a blank reloaded page. If it does, open this page again: it says that the previous run never finished.

The demo itself no longer grows its memory, so a crash here does not mean the demo will crash; it says whether this Safari has the fault.
