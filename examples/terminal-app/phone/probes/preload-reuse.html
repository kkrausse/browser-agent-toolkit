Does this browser reuse a preloaded module without asking?

A frame preloads and imports m.js, whose text changes at every load. A load is "unasked" if the server (here: this page's service worker) got no request for m.js, and "stale" if the frame ran an earlier load's module. Playwright's WebKit 27.2 is stale in about half of the loads of the first two variants and never with Vary: *, which is why the preview's service worker sends that header (report section 10). This is runtime/harness/webkit/preload-reuse/run.ts as a page: the service worker stands in for its server, and each load is a new frame, not a navigation of the tab, so a zero here is weaker evidence than that script's.
